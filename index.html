Обо мне

Цель на AI Цех

Собрать первый набор личных AI-проектов: простые страницы, панели, помощники и прототипы, которые можно показать, улучшать и публиковать.

Следующие 3 шага

  1. Сделать первую личную страницу и запустить ее локально.
  2. Разобраться, как файлы HTML, CSS и JavaScript работают вместе.
  3. Подготовить проект к публикации на GitHub и Vercel.
